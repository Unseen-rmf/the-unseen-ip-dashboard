# 🌐 IP Intelligence Dashboard

A Python-based IP analysis and visualization tool designed for **educational and defensive cybersecurity learning**.

It provides geolocation insights, network metadata, and interactive map exports from publicly available IP data.

## ✨ Features

- 🌍 Public IP lookup (your own IP)
- 🎯 Target IP geolocation analysis
- 📡 ISP / organization detection
- 🔁 Reverse DNS lookup
- 📏 Distance calculation between IP locations
- 🌐 Timezone detection (basic)
- 📊 Multi-IP comparison mode
- 🗺️ Interactive HTML map export (Folium)
- 🖥️ Clean terminal dashboard UI (Rich)
- 🎨 ASCII banner support

---

## 🧠 How It Works

This tool collects **publicly available IP metadata** from online APIs and presents it in a structured dashboard format for educational analysis.

It does NOT:
- Hack or access private systems
- Bypass security systems
- Perform unauthorized scanning
